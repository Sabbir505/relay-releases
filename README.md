# Relay releases

Public distribution point for [Relay](https://ultimate-workspace.netlify.app) — a local-first desktop workspace for AI coding agents. The source code is private; this repo exists only to host the Windows installers and the auto-update feed.

- **Download:** grab the latest installer from [Releases](https://github.com/Sabbir505/relay-releases/releases/latest)
- **Auto-updates:** installed copies of Relay poll `releases/latest/download/latest.json` in this repo
- **Docs, releases list & changelog:** the [landing site](https://ultimate-workspace.netlify.app) ([releases page](https://ultimate-workspace.netlify.app/releases.html))

Older releases of the pre-rebrand app ("Conduit") are mirrored here for download; the source history remains in the private repository.
