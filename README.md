# Relay releases

Public distribution point for [Relay](https://relay-landing.netlify.app) — a local-first desktop workspace for AI coding agents. The source code is private; this repo exists only to host the Windows installer and the auto-update feed.

- **Download:** grab the latest installer from [Releases](https://github.com/Sabbir505/relay-releases/releases/latest)
- **Auto-updates:** installed copies of Relay poll `releases/latest/download/latest.json` in this repo
- **Product info, screenshots, FAQ:** the [landing page](https://relay-landing.netlify.app)

Older releases of the pre-rebrand app ("Conduit") remain attached to the private source repository and are not mirrored here.
